# Supplementary tables

The four XLSX files are byte-for-byte copies of the supplied submission tables.
`tsv/` contains one export per nonempty worksheet, using stored cell values.
Merged-cell blanks, original wording and historical evidence paths are retained.
TSV exports do not preserve workbook formatting or formulas and do not recalculate
any result. `Stage2_validation` in S1 is an empty sheet in the source and was
not exported; Stage 2 data is supplied in S2.
