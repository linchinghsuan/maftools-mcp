Use ANNOVAR.skill to run variant annotation. ANNOVAR is installed at ANNOVAR_test/annovar.

Annotate all VCF files located in ANNOVAR_test/VCFs using hg19 and refGene only. Save all ANNOVAR outputs to ANNOVAR_test/outputs.

After annotation is completed, use maftools-mcp to merge all ANNOVAR_test/annovar_skill+maftools-mcp/*.hg19_multianno.txt files with merge_annovar_to_maf using refBuild=hg19, table=refGene, ens2hugo=true, sep="\t", sampleAnno=null, basename="merged", output_dir="ANNOVAR_test/outputs".

Then use maftools-mcp plot_oncoplot on ANNOVAR_test/annovar_skill+maftools-mcp/merged.maf with top=20 and save the output to ANNOVAR_test/annovar_skill+maftools-mcp/oncoplot.png.

Execution requirements:
- Use the installed ANNOVAR Skill at .codex/skills/annovar/SKILL.md.
- Do not modify source code or the ANNOVAR Skill.
- Record the exact ANNOVAR commands executed in ANNOVAR_test/annovar_skill+maftools-mcp/logs/annovar_commands.log.
- Record environment details in ANNOVAR_test/annovar_skill+maftools-mcp/logs/environment_record.txt, including model gpt-5.5, ANNOVAR path, input directory, output directory, genome build hg19, protocol refGene, and maftools-mcp tool parameters.
- After completion, write a manifest of generated files to ANNOVAR_test/annovar_skill+maftools-mcp/logs/final_file_manifest.tsv.
